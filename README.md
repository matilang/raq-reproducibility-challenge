# RAG Reproducibility Challenge

Knowledge-Intensive NLP Tasks* (Lewis et al., 2021).

## Structure

- `open_domain/` — Open-domain QA reproduction  
- `ms_marco/` — Abstractive QA
- `jeopardy/` —  Jeopardy question generation
- `fever/` — Fact verification reproduction
- `shared/` — Shared utilities
- `presentation/` — Shared slides
